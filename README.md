# The High Point Lounge, Manipal

Run the site locally with:

```bash
npm start
```

Then open http://localhost:8000. You can also open `index.html` with VS Code Live Server
(or any other static server).

- Change the WhatsApp number: js/main.js, variable WA
- Colors and fonts: css/style.css, :root
- Swap the hero video: assets/hero-bg.mp4
